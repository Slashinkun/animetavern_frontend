# AnimeTavern - Frontend

Application web de suivi d’animés développée avec **React**, **Go** et **PostgreSQL**.

Ce projet a été réalisé dans le cadre de l'UE **PC3R** à **Sorbonne Université**.

# Installation

Pour déployer l'application localement, veuillez suivre les instructions suivantes :

Installer NodeJS : https://nodejs.org/fr

Cloner le repositoire : 

`git clone https://github.com/Slashinkun/animetavern_frontend `

Se placer dans le répertoire du client : `cd animetavern_frontend`

Installer les dépendences : `npm install`

Démarrer le client : `npm run dev`

## Backend

Le frontend nécessite du backend pour fonctionner correctement.

Le repositoire du backend est disponible ici :
https://github.com/Slashinkun/animetavern_backend
